# Notice

A notice is a one-line message above the content with optional actions; `warn` by default, `.alarm` for a lost server.

Titan marks only real problems (server lost, VRAM short, slower than usual) with hazard stripes; everything else stays plain. A crash notice can fold the log tail (`.logtail`). Write it as a plain sentence with the fix: "Model file missing – pick another or download it."
