# ProfileCard

A profile card is a saved start configuration: name, backend plate, six fixed metric fields, live t/s while running, and start/stop.

`.pf` with `--b`; `.pf.on` lights the stripe and rim while the profile runs. Before a start, the VRAM forecast (`.fc`) compares free and needed VRAM; when it does not fit, Titan adds hazard stripes. The command line folds into `.pf-cmd`. The consumer provides the profile, its figures and the forecast.
