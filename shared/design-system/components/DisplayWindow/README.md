# DisplayWindow

The big tokens/s figure (`.tps`) is the one number a server card is read by: `t-xl` mono, with the unit beside it.

Dark: ink-white with a halo in the backend colour while busy, muted when idle. Titan: a display window — `disp` glass, `phos` figure, `amber` unit, `fuge` frame; a missing value shows "–" in `amber`.
