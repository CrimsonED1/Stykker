# Badge

A badge names a state in one or two words: a dot plus text on a 10% tint, 4px corners, never a pill.

Variants `good`, `acc`, `warn`, `bad`; `.plain` drops the dot (for a "Hint" label). Titan prints badges as plates: mono capitals, 10px, 1px corners.
Use a badge next to a title or in a notice; for per-server state use the state lamp instead. Tags (`.tag`) are mono labels in a hairline box for facts such as a quant or a context size.
