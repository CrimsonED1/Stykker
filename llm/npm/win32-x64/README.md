# @stykker-llm/win32-x64

Windows-x64 app (self-contained: .NET is included, single exe) for [stykker-llm](https://www.npmjs.com/package/stykker-llm).

**Do not install this package directly** — it is pulled in automatically as an optional dependency of
`stykker-llm`. The app folder (`app/StykkerUI.exe` and `app/stykker.exe`) is added at packaging time by
`build/pack-npm.ps1` in the project repository; it is not part of the repository.
